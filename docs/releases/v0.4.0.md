SuperCommander 0.4.0 brings faster startup, selectable blue and dark red themes, quicker SSH connections and improved keyboard navigation.

### Highlights

- Local panes and settings open before Explorer network discovery. On the test machine, startup IPC fell from 1.76–1.80 seconds to 2–4 ms, and both panes became ready 102–119 ms after WebView navigation instead of 1.93–2.04 seconds. These pane timings exclude native process and WebView startup.
- Separate, remembered palettes: **Midnight blue, Midnight with classic blue (#173E76), graphite with blue panels, and three corresponding dark red palettes** for dark mode; **Sky blue, Ice blue and Azure** for light mode. Changes preview immediately, including menus, dialogs and native glass; a titlebar sun/moon button switches modes without losing either palette.
- Drag the docked terminal's top edge to resize it; its height is remembered and the live shell is resized without restarting. Terminal selections remain visible in blue, red and light themes, including when the terminal loses focus.
- Select a saved SSH connection to connect immediately with its configured authentication. Connection errors open the prefilled form; unknown or changed server keys still require confirmation.
- **Alt+S** now finds the next matching filename without hiding other entries. **Enter / Alt+S** advances and wraps, **Shift+Enter** moves backward, and **Esc** closes quick find. **Ctrl+Shift+F** retains the filename filter.
- Opening a folder focuses the first row, usually `..`; going up focuses the folder just exited, and a drive root focuses its first entry. Filename filter text has enough inner padding to remain visible under the focus border.
- **F9 / Actions → Calculate folder sizes**, also available through **Alt+Shift+Enter**, scans marked folders or all visible folders. Results appear in the Size column, support sorting, show partial results and can be cancelled. Symbolic links and junctions are not followed.
- **F1** has a category sidebar, global search and keyboard navigation; contextual help opens the relevant category. The bottom shortcut bar includes F1 and F9. Settings contains preferences without duplicating the shortcut reference.

### Downloads

- **SuperCommander_0.4.0_x64-setup.exe** — recommended Windows x64 installer; installs WebView2 if needed.
- **SuperCommander_0.4.0_x64.exe** — standalone executable; requires WebView2.
- **SHA256SUMS.txt** — download checksums.
- **BUILDINFO.json** — source commit, Windows CI run and executable hashes.

Builds are unsigned and automatic application updates are not implemented.
