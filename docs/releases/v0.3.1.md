SuperCommander 0.3.1 makes the dual-pane Windows file manager denser and easier to read.

### Changes

- **Alt+S** focuses the active pane's filename filter. Type to narrow the list, press **Enter** to focus the first match, or **Esc** to clear the filter and return to the file list. **Ctrl+Shift+F** remains available; shortcut help and tooltips show both.
- Compact file and Workspace rows are now **26 px** high instead of 32 px. Comfortable rows use **34 px** instead of 40 px.
- Reduced horizontal padding and icon spacing leave more room for filenames.
- Higher text contrast in dark and light themes, with clearer sizes, dates, file types, column headings and navigation labels.

### Downloads

- **SuperCommander_0.3.1_x64-setup.exe** — recommended per-user Windows x64 installer; downloads WebView2 if needed.
- **SuperCommander_0.3.1_x64.exe** — standalone executable; requires WebView2.
- **SHA256SUMS.txt** — download checksums.
- **BUILDINFO.json** — source commit, Windows CI build and executable hashes.

### Validation and limitations

The UI changes passed 51 browser tests and 26 JavaScript unit tests, and were tested in an isolated native Windows app for Alt+S in both panes, Enter/Esc, virtualized row heights and both themes. The release workflow also builds the Windows executable and installer and tests the Rust core, native clipboard, properties, search, transfers, queues, comparison, tooltips, recovery, rename and ZIP operations.

Builds are unsigned and automatic application updates are not implemented. The existing limitations are described in the [README](https://github.com/rihokirss/SuperCommander/tree/v0.3.1#readme). The dependency audit reports no known npm vulnerabilities and one unpatched upstream [RSA advisory](https://rustsec.org/advisories/RUSTSEC-2023-0071.html); see the [dependency review](https://github.com/rihokirss/SuperCommander/blob/v0.3.1/docs/dependencies.md).
