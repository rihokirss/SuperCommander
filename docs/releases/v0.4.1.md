SuperCommander 0.4.1 makes better use of the window and fixes a terminal display issue.

- The F1–F9 buttons now share the bottom status bar and stay compact beside the workspace, giving the file panes more vertical space. Status, transfer and language controls remain available.
- Terminal sizing now accounts for its padding, so the last row and right edge remain visible when the docked terminal is resized or switched to fullscreen.

### Downloads

- **SuperCommander_0.4.1_x64-setup.exe** — recommended Windows x64 installer; installs WebView2 if needed.
- **SuperCommander_0.4.1_x64.exe** — standalone executable; requires WebView2.
- **SHA256SUMS.txt** — download checksums.
- **BUILDINFO.json** — source commit, Windows CI run and executable hashes.

Builds are unsigned and automatic application updates are not implemented. See the [README](https://github.com/rihokirss/SuperCommander/tree/v0.4.1#readme) and the [dependency review](https://github.com/rihokirss/SuperCommander/blob/v0.4.1/docs/dependencies.md).
