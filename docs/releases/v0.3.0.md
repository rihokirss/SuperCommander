SuperCommander 0.3.0 expands the Windows dual-pane file manager with native file clipboard support, richer editing and search, reviewed folder synchronization, recovery of previous versions and safer archive operations.

### Downloads

- **SuperCommander_0.3.0_x64-setup.exe** — recommended per-user Windows x64 installer; downloads WebView2 if needed.
- **SuperCommander_0.3.0_x64.exe** — standalone executable; requires WebView2.
- **SHA256SUMS.txt** — SHA-256 checksums for both downloads.

### What's new since 0.2.0

- Native copy, cut and paste interoperating with Explorer, same-folder duplicates, and clipboard selections bound to the files and SSH sessions originally selected.
- Persistent, named and reorderable bookmarks; file properties, folder sizes, Windows attributes and SSH permissions.
- Keyboard-accessible menus and searchable shortcut help. F9 includes comparison and recovery; Insert marks and advances, Tab switches panes, and Home/End and Page Up/Down navigate the file list.
- Improved F3 viewing and F4 editing, text search, encoding choices, Save As, overwrite checks and protection against closing with unsaved changes.
- Content search with Unicode matches and large-file viewing; results remain available while viewing or editing a match.
- **Shift+F2** folder comparison across local/UNC, SFTP and ZIP sources, with content checks, selectable copy directions and a complete review before queued synchronization.
- **Ctrl+Shift+R** recovery of saved copies and previous versions, with read-only viewing, restoration review and links from Transfers.
- Reviewed bulk rename, including case-only changes and protection against replacement files and changed SSH sessions.
- **Alt+F5 / Alt+F6** ZIP creation and extraction. Inputs are checked against queued snapshots; extraction validates paths and uses private staging files. ZIP64, empty folders, modification times and supported read-only/permission metadata are preserved. Replaced files can be retained as previous versions.
- Stronger transfer cancellation, conflict checks, progress reporting and recovery records for interrupted operations.
- Refreshed dependencies, including Vite 8, TypeScript 7, xterm 6, ZIP 9, russh 0.65 and keyring 4, with compatibility checks for existing Windows credentials.

The existing dark/light/system themes, adjustable glass effect, compact rows, collapsible Workspace, Explorer network locations, OpenSSH connection catalog, server shells and remembered multi-port forwarding remain available. English and Estonian interfaces are included.

### Validation and limitations

The Windows build workflow runs Rust, JavaScript and browser tests, builds the executable and installer, and exercises native clipboard, properties, search, transfers, queues, comparison, tooltips, recovery, rename and ZIP operations. Additional isolated Windows checks cover real OpenSSH, remote editing, shells, forwards and PowerShell/ConPTY. ZIP64 creation and extraction above 4 GiB were tested separately on Windows.

Builds are unsigned and automatic application updates are not implemented. The quick editor handles text files up to 4 MiB. Archives are local ZIP files; encrypted ZIP, 7z and RAR are unsupported. Copying an individual ZIP entry through the browser is limited to 128 MiB; use extraction for larger files. Extraction snapshots compressed inputs in temporary storage, so additional free disk space is required. ProxyJump, ProxyCommand and Match-dependent SSH connections are unsupported; their configuration text is preserved. ACLs, ownership and alternate streams are not cloned. Remote deletion is permanent and asks for confirmation.

See the [README and screenshots](https://github.com/rihokirss/SuperCommander/tree/v0.3.0#readme) for the complete keyboard reference, setup and detailed behavior.

Dependency audits found no known npm vulnerabilities. Rust's RSA dependency still has the unpatched [RUSTSEC-2023-0071 advisory](https://rustsec.org/advisories/RUSTSEC-2023-0071.html); prefer Ed25519 SSH keys where available. See the [dependency review](https://github.com/rihokirss/SuperCommander/blob/v0.3.0/docs/dependencies.md) for versions and remaining upstream advisories.
